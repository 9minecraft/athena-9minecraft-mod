# Athena 9minecraft Mod - Connect Block Textures for Clean Builds

Athena 9minecraft Mod provides connected texture systems for other mods to create smooth block designs. It helps adjacent blocks merge together into one solid surface rather than showing repeating grid lines. The mod adds no standalone items or blocks and works quietly in the background when needed. Features: Lets blocks placed side by side share one continuous surface without repeating square tiles. Connects textures across walls, glass panes, pillars, and horizontal or vertical strips.

## What this build is

An unofficial rebuild of **ThatGravyBoat**'s original work, kept running on current releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Loader: Fabric, NeoForge.
